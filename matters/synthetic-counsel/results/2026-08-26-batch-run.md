# Batch run: 40 questions, one retrieval per question

Date: 2026-08-26. Comparison run against 2026-08-26-megaprompt-baseline.md.
Same corpus (10 files, 320 chunks), same model and settings; only the
protocol changed: batch mode = each question gets its own retrieval pass.

## Conditions

Identical to baseline except protocol: qwen3-14b Q5_K_M, temp 0.7, top_p 0.80,
presence 1.5, top_k 5, min_score 1.0. Scoped lines used --only per firm.

Architecture argument confirmed: per-question retrieval nearly doubled the
correct-outcome rate at the same model and settings.

## NEW FINDING 1: semantic conflation (Q12) — first true wrong answer

Scoped to firm-charlie, "What fee was QUOTED for a provisional filing?"
-> answered "$130 [page 12]". $130 is the USPTO GOVERNMENT fee from the
guide's reference table; Firm Charlie quoted no service fee. The citation is
valid, the number is verbatim, the number check correctly stayed silent, and
the claim is still wrong. Cite-or-refuse guards PROVENANCE, not SEMANTICS.
A category error with a real citation passes every deterministic check.
(Q14, which asked for the government fee explicitly, was answered correctly:
the failure is conflation under an ambiguous question, not retrieval.)

## NEW FINDING 2: gate miscalibration under --only scoping

All 3 gate refusals occurred in scoped mode (Q10 Bravo fee — present in the
folder's only file; Q15 Echo reason; Q16 Delta responded?). Causes:
1. BM25 scores deflate when the chunk pool shrinks (IDF collapses), so the
   full-corpus gate of 1.0 over-refuses tiny scopes (real matches ~0.55-0.62).
2. No stemming: "fee" != "fees", "application" != "applications". Bravo's
   email says "provisional applications" and never contains the word "fee".
   Same cause degraded Q9 (missed the fee-schedule table for "fees quoted").

Candidate fixes (not yet applied): light plural stemming on both sides;
scope-aware gate (scale min_score with pool size, or gate on the unscoped
corpus). Decision pending.

## Standing finding (third occurrence): zero-overlap paraphrase

Q35 "Which law office turned us down?" (law office/turned down vs
firm/declined) false-refused. Lexical retrieval cannot bridge zero word
overlap. The argument for dense retrieval in v1. Note Q33 ("temporary patent
application") PASSED solo this run — partial overlap can be enough.
