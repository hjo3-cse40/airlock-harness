# Run 7: Qwen3-8B Q5_K_M on personal M3 (18 GB)

Date: 2026-08-27. Same corpus (10 files, 320 chunks), same harness
(hybrid RRF W_DENSE=0.5, two-key gate, prompt rule 7), same 40 questions
as 2026-08-26-hybrid-halfweight.md. Change under test: **model and machine**,
not retrieval. Work-laptop 14B Q5_K_M / 32k is replaced by the 18 GB
development profile.

## Conditions

- Machine: personal M3 MacBook Pro, 18 GB unified memory
- Chat: `qwen3-8b` (unsloth Qwen3-8B-GGUF, Q5_K_M) via LM Studio 127.0.0.1:1234
- Load: context 8,192; Flash Attention ON; KV cache Q8_0; all 36 layers GPU;
  thinking OFF (`reasoning_tokens` 0 on smoke tests)
- Embedder: `text-embedding-nomic-embed-text-v1.5@q8_0` (same as run 5–6)
- Request (ask.py): temp 0.7, top_p 0.80, presence_penalty 1.5, max_tokens 1,200
- Harness: top_k 5, min_score 1.0, dense_min 0.5; scoped lines used `--only`
- Protocol: `python3 ask.py --matter synthetic-counsel batch test-questions.txt`

Selftest and the Alpha-provisional smoke test passed before the batch.
An unscoped fixtures trap ("metal-1 CD in the shipment note") leaked 1.2 nm
from por-revC; the same question with `--only unanswerable.md` refused
correctly. That is 8B + distractor-in-S1, not a server failure.

Highest correct-outcome rate recorded on this 40-question set. Previous
peak was run 4 at 36/40 (90%) on Qwen3-14B. This is a **model swap**, not
a harness win: do not quote it as "the pipeline improved to 92.5%."

## Checker note (Q16)

Four `UNVERIFIED NUMBER` warnings, all on Q16: `2026`, `08`, `12`, `19`
parsed out of `2026-08-12` / `2026-08-19`. Those strings live in markdown
**headings**; `verify_numbers` only reads chunk **body**. Not invented
money. Run 4 had zero warnings because 14B refused instead of restating
the dates. Treat as checker noise, not a fabrication fail.

## How to read this for the two-machine split

The 18 GB M3 + 8B Q5_K_M profile is enough to run the synthetic bench
without swapping. Remaining errors are the same retrieval classes as 14B
hybrid, not "small model invents numbers." A later 14B Q4_K_M load on this
laptop, or a 14B re-run on the M5 with the same hybrid weights, is the
fair quality comparison. This run is the 8B data point.
