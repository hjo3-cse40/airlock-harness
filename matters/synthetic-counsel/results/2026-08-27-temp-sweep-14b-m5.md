# Temperature sweep: Qwen3-14B Q5_K_M on work M5 Pro (24 GB)

Date: 2026-08-27. Identical protocol to the 8B sweep
(`2026-08-27-temp-sweep-8b-m5.md`): same current test-questions.txt (Q17/Q18
`--diverse --top-k 8`), same harness, same temps 0.0-0.7, one batch per temp,
only the LOADED MODEL changed (8B -> 14B). This is the apples-to-apples
8B-vs-14B run. Auto-scorer is calibrated to the 8B's temp-0 39/40; the 14B's
failing answers were read by hand and confirmed as real (not terseness
artifacts).

## Configuration (held constant vs the 8B run)

- Machine: work M5 Pro, 24 GB. Model: `qwen3-14b` Q5_K_M via LM Studio.
- Embedder: `text-embedding-nomic-embed-text-v1.5@q8_0` (hybrid, confirmed loaded).
- Load context 32k (immaterial: questions use 1-4% of the window).
- Request temp per sweep; top_p 0.80, presence 1.5, max_tokens 1200.
- Harness: top_k 5, min_score 1.0, dense_min 0.5.

## Findings vs the 8B

1. The 14B scores 37-38/40, consistently EQUAL OR ONE-TO-TWO BELOW the 8B's
   38-39/40 on this set. The 8B is at least as accurate here.
2. Two persistent 14B misses the 8B got RIGHT:
   - **Q12**: 14B presents the $130 USPTO government fee as "the fee quoted"
     for a provisional (rule-7 government-vs-firm conflation). Fails 6/8 temps.
     The 8B refused correctly at all temps. Hazard for a fee-extraction task.
   - **Q16**: 14B false-refuses "Did Firm Delta respond?" ("Not specified")
     at ALL 8 temps. Answer is derivable (two outbound, no reply). Matches the
     known "status/absence questions may need unscoped runs on 14B" note.
3. **Q35 fails on BOTH models at EVERY temp.** Confirmed: it is a retrieval/
   embedder limitation, NOT model size. No model swap fixes it.
4. The 14B is terser (cited, little padding) and much faster in wall-clock.
   For extraction that output style is arguably preferable, but the temp-0
   drift on Q12 lands on exactly the distinction this task cares about.

## Takeaway

On this extraction set the 8B is slightly more reliable than the 14B, mainly
because the 14B drifts on Q12 and false-refuses Q16 at temp 0. The 14B's edge
is terseness and wall-clock speed, not accuracy. Neither fixes Q35. Single
sample per temp>0, so the moving second failure is noise; the consistent
signal is Q12 (14B) and Q16 (14B) and Q35 (both).
